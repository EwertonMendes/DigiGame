# Changelog

This changelog summarizes player-visible milestones. It is not an exhaustive engineering log.

## Unreleased — vertical-slice preparation

### Available in the current prototype

- Rebuilt the isometric hub foundation with desktop and touch movement, interaction, and a test-battle transition.
- Expanded tactical combat with movement, target patterns, techniques, turn scheduling, enemy AI, combat presentation effects, and responsive HUD layouts.
- Added persistent Digimon instances, experience and battle rewards, stat calculation, and progression data validation.
- Added DigiLab foundations for branching digivolution and degeneration.
- Added automated browser checks for desktop, mobile, combat, and presentation effects.
- Added a Web export pipeline and mobile browser support.

### In progress

- Assemble the hub → preparation → mission → battle → reward → return flow into one coherent 20–30 minute vertical slice.
- Improve onboarding, controls, and mobile readability.
- Replace development-only shortcuts and temporary tools in the normal player path.
- Prepare a small closed playtest before opening the browser build publicly.

### Communication foundation

- Added a multilingual project landing page that honestly distinguishes implemented, experimental, and planned work.
- Added a 90-day publishing calendar, community setup guide, feedback workflow, and release gate.
- Kept the game build unlinked from the public landing page until the vertical-slice gate is met.
