# City asset kit

These PNGs are deliberately included in DigiGame at the user's explicit request.
Source: the supplied `Darkmoon_City_Assets_Only.zip`, derived from Digimon World
Dusk. This records the supplied source and user authorization; it does not assert
an independent third-party redistribution license.

* `tiles_8x8.png`: original RGBA atlas, unchanged; 32 columns, 3,825 valid cells.
* `pieces.png`: complete modules assembled from source cells using
  `experiments/darkmoon_sandbox/brushes.json`; no recoloring or resampling.
* `manifest.json`: SHA-256 hashes and source metadata.

No original maps, reference backgrounds, 16/32-pixel atlases, or temporary images
are included. The complete source atlas supports authoring new scenery; its
unused tail is excluded from the TileSet.
