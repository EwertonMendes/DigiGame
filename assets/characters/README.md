# Character Sprite Provenance

DigiGame contains legacy prototype character art from commercial Digimon games. These sprites are **not** open-source assets.

The normalized runtime sheets used by the current battle scene are committed to the repository. A clean checkout therefore does not have to contact sprite-hosting sites before the game can run. The old fetch/preparation scripts remain only as optional provenance/reproduction tools and are no longer part of normal Web CI.

Every `directional_12` sheet follows one complete runtime contract: `down_left`, `down_right`, `up_left`, `up_right`, with `idle`, `step_a`, `step_b` inside each direction. The source archive frequently stores direction groups and the corresponding right-facing poses in different authored orders. `database/ds-direction-review-map.json` classifies those authored layouts as reusable source conventions; `tools/materialize_ds_direction_registry.py` converts the selected convention into the one canonical runtime order and verifies phase pairing before the strip is built. All frames in one species share a uniform bottom-center cell anchor, and the generated animated audit preserves that registration instead of trimming each preview frame again.

The current reviewed source conventions are data, not runtime exceptions: `canonical_rows` (`DL, DR, UL, UR`), `rear_rows_first` (`UL, UR, DL, DR`), `compact_interleaved` (`DL, UL, DR, UR`), and `compact_interleaved_rear_reversed` (`DL, UR, DR, UL`). The last convention is shared by multiple original WtW sheets, including Gabumon, Tapirmon, and Aruraumon. Runtime code never checks a Digimon name to flip or swap a facing; every asset reaches the same `directional_12` contract before Godot loads it.

Agumon, Greymon, and MetalGreymon remain separately preserved reviewed references where required by their original extraction paths. The complete Fresh/In-Training/Rookie WtW roster is otherwise rebuilt from pinned original source hashes through `database/ds-direction-registry.json` into each character's committed `field.png` and `field.json`.

Koromon and Tanemon originate from the With the Will sprite archive used by this prototype. Their source sheets use different authored direction-group conventions, which are represented in the semantic review map rather than by runtime mirroring or species-specific movement code.

Veemon uses the latest transparent spritesheet supplied directly by the project owner in the September 9, 2026 correction pass. The current runtime file is `assets/characters/veemon/field.png` and uses the `spaced_9_32` runtime layout: nine 32x32 cells separated by one transparent spacer column. It must not be sliced with `Sprite2D.hframes = 9`; the runtime crops each exact 32x32 cell at a 33-pixel stride. The right-facing variants are horizontal mirrors of the corresponding supplied left-facing walk frames.

MetalGreymon uses the Digimon World DS sheet listed as asset `48322` on The Spriters Resource, with the project owner's With the Will / historical Photobucket link as the original reference. The exact downloaded source used for the September 12, 2026 extraction is 395x432 and has SHA-256 `2f370926a0585787dfbae2b575509f8698a80539c8a68c87d3586b1d99a05665`. A second inspection pass found all twelve authored small field frames in that sheet: two three-frame front-facing columns and two three-frame rear-facing columns. `tools/fetch_metalgreymon_field.py` extracts those four directions directly and writes `assets/characters/metalgreymon/field.png` as a clean 12-cell `directional_12` sheet. No frame is mirrored, resized, repainted, or color-keyed; the purple credit panels and watermarks sit outside the exact alpha-backed source boxes.

`tools/validate_runtime_assets.py` verifies all battle-critical committed character sheets together with the terrain, VFX, and UI fonts without making network requests. DS rebuild validation additionally proves that generated metadata, source-group order, phases, anchors, and source hashes match the reviewed registry.

Rights to Digimon and the official game artwork remain with their relevant Digimon/Bandai Namco rights holders. No free-content license is claimed. These assets are suitable only for the current fan/prototype context and should be replaced by original or properly licensed artwork before commercial distribution.
