# Digi UI Dark — Kenney Sci-Fi derivative

This folder contains a small dark-mode derivative set created for DigiGame from the visual language and geometry of **Kenney UI Pack - Sci-Fi**.

- Original asset pack: **UI Pack - Sci-Fi**
- Author/publisher: **Kenney**
- Official source: https://kenney.nl/assets/ui-pack-sci-fi
- Verification/mirror used for source inspection: https://github.com/ETdoFresh/kenney.nl/tree/45df48c4d45f8716216b1a9e22df0b69cd9f5932/uipack-space
- Pinned mirror commit: `45df48c4d45f8716216b1a9e22df0b69cd9f5932`
- License: **CC0 1.0 Universal / public domain dedication**
- Attribution required: **No**
- DigiGame modifications: rebuilt as dark scalable SVG frames, with DigiGame cyan/gold accents and higher contrast for the existing dark presentation.

Files used by the runtime skin:

- `panel.svg`
- `panel_strong.svg`
- `button_normal.svg`
- `button_hover.svg`
- `button_pressed.svg`

Text is intentionally not baked into any image. Godot `Label` and `Button` controls remain responsible for all copy so future localization can resize and replace strings without regenerating art.
