# Battle Operator icon family

These SVGs are original DigiGame UI assets authored specifically for the Battle Operator.

Design contract:
- 64 x 64 viewBox.
- Monochrome white source artwork; semantic colour is applied by Godot at runtime.
- Rounded 4 px strokes unless a filled geometric mark is required.
- No embedded fonts, raster images, filters, external references or runtime-generated SVG markup.
- Program icons form a progressive data-core family from Fresh through Mega.
- Battlefield icons communicate authored map geometry rather than generic movement.
- Section and action icons are scoped to Battle Operator concepts and must not reuse combat/stat semantics.
