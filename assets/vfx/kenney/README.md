# Kenney Particle Pack — combat VFX

The combat VFX PNGs in this directory are **committed to DigiGame** and loaded from `res://assets/vfx/kenney`. Runtime combat does not download effects from the internet.

- Pinned commit: `ab7086639ee73be31abd87feb21bf1402d4e8144`
- Files used: `slash_03.png`, `spark_04.png`, `magic_03.png`, `flare_01.png`, `muzzle_01.png`
- Attribution required: no (CC0); provenance is retained here for reproducibility.

`tools/fetch_cc0_assets.py` is now optional only. Normal CI validates these committed binaries with `tools/validate_runtime_assets.py` and does not fetch them.
