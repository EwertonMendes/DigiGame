# Digimon World DS combat audio selection

These four WAV files were selected from the Digimon World DS sound-effect archive distributed by The Sounds Resource. They are **not CC0/open-source assets** and are intentionally isolated from the reusable VFX library.

Source page: https://www.sounds-resource.com/ds_dsi/dgmnworldds/
Captured archive asset: `400142`

| Runtime file | Source WAV | Purpose |
| --- | --- | --- |
| `normal-attack-whoosh.wav` | `053.wav` | normal physical attack release / whoosh |
| `normal-attack-impact.wav` | `031.wav` | normal attack impact |
| `technique-cast.wav` | `043.wav` | technique cast / release |
| `technique-impact.wav` | `068.wav` | technique impact |

The project makes no claim of ownership over the original Digimon audio. Keeping these cues in their own directory makes later replacement with original or separately licensed audio straightforward without changing combat presentation code.
